\# 装机侠 · 台式电脑 DIY 配置器

静态页面 + GitHub Actions 每日自动更新京东价格。



\## 本地运行

npm run update        # 手动跑一次价格采集

npx serve .           # 启动本地服务器预览（不要用 file:// 直接打开）



\## 维护说明

\- 新增/更换商品：修改 config/skus.json（SKU 取自京东商品页 URL）

\- 淘宝价格不自动采集（接口有签名加密），在 index.html 的 DB 中人工维护

\- p.3.cn 为公开历史接口，若失效请更换脚本中的价格源或改用京东联盟官方接口

\- 合规声明：仅采集公开价格，每日一次低频请求，仅限个人学习使用
